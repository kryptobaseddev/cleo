# Orca plugin typings (snapshot)

The typings Orca generates for plugin authors, copied from Orca **1.4.255**: the `engines.orca`
floor of `packages/adapters/orca-plugin`. `packages/adapters/orca-plugin/tsconfig.json` type-checks
the plugin against this folder, so CI (which has no Orca) can run it through the root `tsc -b`.

Checking against the floor is deliberate: the plugin must compile against the oldest Orca it
claims to run on, whatever newer version a developer has installed.

Do not edit the `.d.ts` files. They are generated by Orca
(<https://github.com/stablyai/orca>, MIT License, Copyright (c) 2026 Lovecast Inc.).

## Refreshing

Only when `engines.orca` in `packages/adapters/orca-plugin/orca-plugin.json` is raised, with that
Orca version installed:

```sh
orca plugin types packages/adapters/orca-plugin --json
for n in orca orca-host orca-frame orca-worker orca-services orca-testing; do
  cp packages/adapters/orca-plugin/.orca/types/$n/index.d.ts packages/adapters/orca-types/$n/index.d.ts
done
pnpm exec tsc -b packages/adapters/orca-plugin
```

Then update the version named at the top of this file.
